# ObanimiStudio Website

Official ObanimiStudio website for digital products, music, technology and creative solutions.

## Brand identity
The black, gold and white **OS logo** is the primary ObanimiStudio brand logo. It is used for the website header, footer, app icons and social metadata.

## Hosting
Hosted with **GitHub Pages only**. Netlify is not required.

Public site: https://obanimistudio-star.github.io/obanimistudio-website/

## Structure
- `index.html` — main site
- `styles.css` — premium black/gold responsive design
- `script.js` — mobile navigation and footer year
- `manifest.webmanifest` — installable web app settings
- `service-worker.js` — offline/static cache
- `assets/brand/` — official brand assets
- `assets/icons/` — favicon and app icons

## Brand line
**One studio. Many expressions.**
